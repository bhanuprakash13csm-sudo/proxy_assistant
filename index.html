Features

  • System Diagnostics: Real-time tracking of CPU load, RAM status, battery health, and storage utilization.
  • Hardware Controls: Seamlessly adjust volume levels and screen brightness via voice commands.
  • Screen OCR & Vision: Locate elements on your screen instantly or run live visual context monitoring.
  • Dictation & Typing Mode: Advanced continuous hands-free text transcription and smart editing mode.
  • Gesture & Voice Navigation: Use webcam hand-tracking gestures or voice-driven cursor controls.
  • Sleep Mode & Custom Naming: Automatically sleeps when idle and awakens instantly to your custom assistant name.

How to Download & Setup

Download the latest package directly, extract it, and run your personal assistant profile.

Download for Windows (ZIP)

Quick Requirements & Steps:

  • Windows OS environment.
  • Make sure Tesseract OCR is installed at C:\Program Files\Tesseract-OCR for screen text features.
  • Extract the downloaded zip file and double-click proxy_assistant.exe to run your first-time configuration setup.
